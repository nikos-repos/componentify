GUIDE / HOVER LIST INDEX

Overview

A vertical index of large nav items. At rest each line is dim with a hairline beneath; on hover it brightens, indents, and gains a bullet. The intro draws each separator left to right while the label types in letter by letter.

When to use

Primary navigation on a focused landing or portfolio home, four to six items. Beyond that, condense labels or move to a menu. Keep each label to one word so the typing reveal reads clean.

Spec

Tokens
--grey-dim rest, --white hover, --line separators
Motion
separator scaleX + char stagger, 0.15s per item
A11y
list semantics, per-char spans built without innerHTML
Rest state
dim passes the large-text 3:1 threshold

Anti-patterns

Do not animate the indent with width, use padding-left. Do not split text with innerHTML, build spans safely. The bullet is a hover reward, not a constant.

<script>
/* Ordered schema:
   0. invisible until 0.75s
   1. hairline separators expand left → right, top row first
   2. text types in letter-by-letter alongside its separator
   Hover behavior (white / indent / bullet) is pure CSS from the kit. */
const list  = document.getElementById("list");
const items = gsap.utils.toArray(list.querySelectorAll("li"));

// split each label into per-character spans (safe DOM building, no innerHTML)
items.forEach(li => {
  const txt = li.querySelector(".txt");
  const chars = txt.textContent.split("");
  txt.textContent = "";
  chars.forEach(c => {
    const s = document.createElement("span");
    s.className = "ch";
    s.textContent = c;
    txt.appendChild(s);
  });
});

function listIntro(){
  const tl = gsap.timeline({delay:0.75, defaults:{ease:"power2.inOut"}});
  tl.set(list, {autoAlpha:1});
  items.forEach((li, i) => {
    tl.fromTo(li.querySelector(".sep"), {scaleX:0}, {scaleX:1, duration:0.6}, i * 0.15)
      .from(li.querySelectorAll(".ch"), {autoAlpha:0, duration:0.02, stagger:0.05, ease:"none"}, "<");
  });
  return tl;
}

let tl = null;
const mm = gsap.matchMedia();
mm.add({
  full:   "(prefers-reduced-motion: no-preference)",
  reduce: "(prefers-reduced-motion: reduce)"
}, (ctx) => {
  if (ctx.conditions.full) tl = listIntro();
  else gsap.set(list, {autoAlpha:1});
});
</script>
